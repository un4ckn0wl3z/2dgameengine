# 2D C++ Game Engine (ECS Architecture)
A lightweight 2D game engine written in modern C++, inspired by Gustavo Pezzi’s (Pikuma) engine architecture.

### Features

- Entity–Component–System (ECS) architecture for clean, scalable game logic
- Event-based Publish/Subscribe system for decoupled gameplay events
- Lua scripting integration for flexible game logic and rapid iteration
- Debug menu using Dear ImGui for real-time inspection and tuning
- SDL2 rendering and input handling for cross-platform graphical output
